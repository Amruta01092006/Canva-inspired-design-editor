# Canva Pro — Graphic Design Studio

### Create. Customize. Design.

CanvasCraft is a Canva-inspired web-based graphic design editor that allows users to create and customize visual designs through an interactive and user-friendly interface.

The platform aims to make graphic designing simple and accessible by providing essential editing tools, customizable elements, and an intuitive design workspace.

## ✨ Features

* **Interactive Design Canvas:** Create and edit designs on a flexible workspace.
* **Text Editing:** Add text and customize font styles, sizes, colors, and alignment.
* **Shapes & Elements:** Insert and customize different shapes and design elements.
* **Image Uploads:** Upload personal images and incorporate them into designs.
* **Background Customization:** Change canvas backgrounds and colors.
* **Drag & Drop:** Move, resize, and rotate design elements.
* **Customization:** Modify colors, outlines, sizes, and other element properties.
* **Undo & Redo:** Easily reverse or restore editing actions.
* **Save Designs:** Save and reopen your creative projects.
* **Export Designs:** Download completed designs in PNG or JPG format.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/CanvasCraft.git
```

### 2. Navigate to the Project

```bash
cd CanvasCraft
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local development URL displayed in your terminal to access CanvasCraft.

## 🎯 Project Objective

The objective of CanvasCraft is to develop an accessible and interactive graphic design platform that simplifies the process of creating digital designs.

It focuses on providing essential design functionalities through a clean interface while exploring modern frontend development, interactive canvas manipulation, and state management.
